## Problem

### Worked example - Print with Custom Separator

In this example, we practice using the `print()` function with a custom separator. The goal is to print a list of fruits separated by the string " | ".

For instance, you can display four fruit names: "apple", "banana", "cherry", and "date". By using the `sep` parameter in `print()`, you can control what appears between each name.

When executed, the code will output:

```
apple | banana | cherry | date

```

This demonstrates how to customize the output by specifying a separator. You can experiment by changing the fruit names or the separator to see how the output updates!

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-31T13:00:27.868Z  

```py
# The sep parameter is used to specify the string that separates the items when printed.

# In this example, the items "apple", "banana", "cherry", and "date" are separated by " | ".

print("apple", "banana", "cherry", "date", sep=" | ")

```
