## Problem

### Count Characters in a Favorite Quote

You have a famous quote: "To be or not to be, that is the question."

Your goal is to determine how many characters (including letters, spaces, and punctuation) are in this quote using Python’s built-in len() function.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-11T01:15:38.747Z  

```py
# Define a string variable with a famous quote
quote = "To be or not to be, that is the question."

# Your code to find the length of the quote goes here
print(len(quote))
```
