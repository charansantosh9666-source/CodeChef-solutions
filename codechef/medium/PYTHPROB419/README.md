## Problem

### Find the ocean in a nature description

You have a sentence, for example, "The ocean is vast and full of mysteries." and you want to locate the substring "ocean" in this string.

The `find()` method will return the starting index of the substring or -1 if it doesn’t appear.

Follow the comments given in the IDE and output your solution to the console.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-21T16:32:11.284Z  

```py
# Define a sentence  
sentence = "The ocean is vast and full of mysteries."

# Use the find() method to get the starting index of the word "ocean"
index=sentence.find("ocean")
# Print the index where "ocean" starts in the sentence
print(index)
```
