## Problem

### Quote Crafting- Mixing it Up

In this task, your goal is to create and print a string containing the following text with nested quotes:

```
He whispered, "The guide said, 'It's called the "treasure of wisdom" for a reason.'"

```

Notice how the string contains:
• Double quotes around "The guide said…"
• Single quotes around It’s called…
• Additional double quotes within those single quotes for "treasure of wisdom"

Once you’ve created and printed the string, click submit to check your output.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-11T01:10:20.005Z  

```py
# Define a string with multiple levels of nested quotes
my_string = "He whispered, \"The guide said, \'It\'s called the \"treasure of wisdom\" for a reason.\'\""

# Print the string to verify it is correctly formatted
print(my_string)
```
