## Problem

### Extracting Fruits from a String

You have a string of fruits separated by semicolons "apple;banana;cherry;date;fig", and you want to split them into a list of individual fruit names using Python’s split() method.

Output the list to the console.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-26T02:01:40.565Z  

```py
# Define a string containing a list of fruits separated by semicolons
fruit_list = "apple;banana;cherry;date;fig"

# Split the string into a list using ";" as the delimiter

fruits=fruit_list.split(";")
# Print the resulting list of fruits
print(fruits)

```
