## Problem

### Write a Poem with Multi-line Strings

You want to store and display a short poem about nature in Python without losing its formatting or line breaks. Python’s triple-quoted strings let you include multiple lines easily, making it convenient to preserve spacing and newlines in the final output.

 **Expected Output** 

```
The sun shines bright,
The birds take flight,
In the lush green trees,
Nature whispers to me.

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-11T01:12:07.237Z  

```py
# Create a multi-line string for a poem about nature
poem = """The sun shines bright,
The birds take flight,
In the lush green trees,
Nature whispers to me."""

# Print the poem
print(poem)

```
