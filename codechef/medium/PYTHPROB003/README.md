## Problem

### Worked Example - Declare Your Age

In this example, we demonstrate how to declare a variable for age and verify that it is an integer in Python.

You can store the integer 30 in a variable named `my_age`, and then use the `type()` function to check what kind of data type Python recognizes this variable as.

When executed, the code might produce an output like this:

```
<class 'int'>

```

This output confirms that the variable `my_age` is of type "int" (integer). This example illustrates how to effectively check data types in Python.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-01T11:30:11.075Z  

```py
# Declare a variable to store age
# Replace 30 with your actual age when using this code
my_age = 30  

# Print the data type of the variable 'my_age'
# This will output: <class 'int'> because 'my_age' is an integer
print(type(my_age))  
```
