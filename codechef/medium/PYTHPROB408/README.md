## Problem

### Validate Age

In this example, we demonstrate how to use Python’s `isdigit()` method to check if a user’s input for age contains only digits. This is a common validation step to ensure that only numeric values are processed where numerical data is expected.

Consider the following variable:

```
user_age = "25"

```

When the given code is executed, the output will be:

```
True

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-18T06:53:42.339Z  

```py
# User input (simulating a form entry)
age = "25"

# Check if the input contains only digits
is_numeric = age.isdigit()

# Print the result of the check
print(is_numeric)
```
