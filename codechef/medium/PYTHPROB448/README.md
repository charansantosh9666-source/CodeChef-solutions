## Problem

### Worked Example - Validate Email Format

In this example, we demonstrate how to use Python’s `startswith()` method to check whether an email address starts with a specific domain pattern. The requirement is that the email address should begin with "company-name-".

Consider the following variable:

```
email_address = "john-d007@company.com"

```

When the given code is executed, the output will be:

```
False

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-27T04:28:12.614Z  

```py
email_address = "john-d007@company.com"

print(email_address.startswith("company-name-"))


```
