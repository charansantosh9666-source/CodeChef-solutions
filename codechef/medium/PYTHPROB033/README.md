## Problem

### Worked example - Calculate Volume of a Cube

In this example, we calculate the volume of a cube using Python’s power operator (**). This demonstrates how to perform exponentiation.

The formula for finding the volume (V) of a cube is:
[ V = a^3 ]
where (a) represents the length of one side of the cube. For instance, if (a = 4), then:
[ V = 4^3 = 64 ]

This calculation shows that a cube with a side length of 4 has a volume of 64 cubic units. You can explore the effect of changing the side length on the volume using the power operator in Python.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-03T02:06:41.355Z  

```py
# Set the side length of the cube
side_length = 4 

# Calculate the volume of the cube using the power operator 
# (side_length raised to the power of 3)
volume = side_length ** 3 

# Print the calculated volume of the cube
print(volume)
```
