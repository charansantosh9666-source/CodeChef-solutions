## Problem

### Validate Product Code

You have a product code "prod-12345" and you need to verify it begins with "prod-".

This ensures consistency for all product codes in the inventory management system.

Output the result to the console based on the comments in the IDE.

### Expected output

```
True

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-27T04:28:53.574Z  

```py
# Declare a string with a single product code
product_code = "prod-12345"

print(product_code.startswith("prod-"))

```
