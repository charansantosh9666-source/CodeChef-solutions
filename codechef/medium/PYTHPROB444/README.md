## Problem

### Find the Output

What will be the output of the following code?

```
my_string = "Python"
result = "".join(my_string)
print(result)

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-27T04:25:02.617Z  

```cpp
word = "PYTHON"  # Given string

# Use join() to insert '-' between each character
formatted_word = "-".join(word)

# Print the formatted word
print(formatted_word)
```
