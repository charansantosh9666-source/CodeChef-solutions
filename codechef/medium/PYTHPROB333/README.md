## Problem

### Count Characters in a Greeting

In this example, we demonstrate how to count the number of characters in a greeting string using Python’s built-in `len()` function.

The length of a string is the total number of characters it contains, including letters, spaces, and punctuation. For example, when you use `len()` on the string `"Hello World"`, it will return the total count of all characters.

Consider the following greeting string:

```
greeting = "Welcome to Python Programming!"

```

When printed, the length will appear as follows:

```
30

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-11T01:14:04.058Z  

```py
# Define a string variable with a message
my_greeting = "Welcome to Python Programming!"

# Use the len() function to calculate the length of the string
length_of_greeting = len(my_greeting)

# Print the length of the string
print(length_of_greeting)  # Output: 30, as the string contains 30 characters, including spaces and punctuation
```
