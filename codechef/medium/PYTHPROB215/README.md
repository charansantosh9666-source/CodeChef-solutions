## Problem

### Calculate Total Material Cost

In this task, you are required to write a program to calculate the total cost of construction materials, using float multiplication and integer addition.

 **Data Values** 

- Each unit of material costs 12.75 dollars (float).
- You need 150 units (integer).
- There is a flat delivery charge of 50 dollars (integer).

 **Expected Output** 
After performing the calculations, your program should print the total cost as follows:

```
1962.5

```

Feel free to adjust the cost per unit, the number of units needed, or the delivery charge to see how the total cost changes!

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-07T01:24:54.107Z  

```py
# Declare the cost per unit as a float
cost_per_unit = 12.75  

# Declare the number of units needed as an integer
units_needed = 150  

# Declare the delivery charge as an integer
delivery_charge = 50  

# Calculate the material cost by multiplying cost per unit with units needed


# Add the delivery charge to calculate the total cost
total_cost=(cost_per_unit* units_needed)+delivery_charge

# Print the total cost
print(total_cost)
```
