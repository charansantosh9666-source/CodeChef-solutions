## Problem

### Trim Whitespace from a Animal Title

In this task, you are required to remove leading and trailing spaces from an animal name and convert it into title case for standard formatting.

You have the following details:

`animal_name` = `" white tiger "`

 **Expected Output** 
After performing the above steps, your program should print the results as follows:

```
  white tiger  
White Tiger

```

Feel free to change the input string to see how the output updates!

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-15T08:54:08.996Z  

```py
# Step 1: Declare the animal name with extra spaces
animal_name = "  white tiger  "

print(animal_name)
print(animal_name.strip())
```
