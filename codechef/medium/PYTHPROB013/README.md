## Problem

### Worked example - Score Difference Calculation

In this example, we demonstrate how to subtract one player's score from another to determine how many more points one player has.

Consider the following scores:

- Player A: 28 points
- Player B: 15 points

By subtracting Player B’s score from Player A’s, you can find the difference.

When executed, the code will display:

```
13

```

This output indicates that Player A scored 13 more points than Player B, illustrating the concept of subtraction in Python effectively.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-01T11:38:15.715Z  

```py
# Assigning scores to two players
player_a_score = 28  # Score of Player A
player_b_score = 15  # Score of Player B

# Calculating the score difference between Player A and Player B
score_difference = player_a_score - player_b_score  # Subtracting Player B's score from Player A's score

# Printing the score difference to the console
print(score_difference)  # Output: 13
```
