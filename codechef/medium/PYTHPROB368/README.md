## Problem

### Convert a greeting message to uppercase

In this example, we demonstrate how to use the `upper()` method to convert a greeting message to uppercase. This method helps transform all letters in a string to uppercase format.

Consider the following string:

```
greeting = "hello, how are you?"

```

When the given code is executed, the output will be:

```
HELLO, HOW ARE YOU?

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-15T08:24:31.482Z  

```py
# Define the original greeting message
greeting = "hello, how are you?"

# Convert the greeting to uppercase using the upper() method
uppercase_greeting = greeting.upper()

# Print the uppercase greetings
print(uppercase_greeting)
```
