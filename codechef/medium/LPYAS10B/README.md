## Problem

Print the following pattern (check the sample output).

Input
Output

```
 
```

**
***

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-27T05:08:43.001Z  

```py
# cook your dish here
for i in range(5):
    
    for j in range(i+1):
        print("*",end="")
    print()
```
