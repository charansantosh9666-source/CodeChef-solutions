## Problem

### The Datatype of Speed

Consider the following Python code:

```
distance = 100.0  # Float
time = 4  # Integer
speed = distance / time

```

What will be the data type of the variable `speed` after the division operation?

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-07T01:25:52.578Z  

```cpp
# Declare the total distance traveled as a float
total_distance = 450.75  

# Declare the total fuel consumed as a float
total_fuel = 36.5  

# Calculate the average fuel efficiency
fuel_efficiency = total_distance / total_fuel  

# Print the average fuel efficiency
print(fuel_efficiency)
```
