## Problem

### Format City Names

In this example, we demonstrate how to use Python's `title()` method to convert a list of city names into title case. Title case capitalizes the first letter of each word, making the text look more polished.

Consider the following string:

```
city_names = "new york, los angeles, chicago, houston"

```

When the given code is executed, the output will be:

```
New York, Los Angeles, Chicago, Houston

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-15T08:36:57.001Z  

```py
# Assigning the string with city names to the variable city_names
city_names = "new york, los angeles, chicago, houston"

# Applying the title() method to convert the city names to title case
formatted_city_names = city_names.title()

# Printing the formatted city names in title case
print(formatted_city_names)
```
