## Problem

### Worked example - Print formatting basics

In this example, we demonstrate how to use f-strings in Python to include integer values in the output, making it clear and straightforward.

For instance, you can display information about a student’s scores in different subjects:

When executed, the code could produce an output like this:

```
Math marks are: 90, Science marks are: 85, English marks are: 88

```

In this output, each integer value represents the score in the respective subject, clearly displaying the student's performance. This method ensures that the output is clean and easy to read.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-31T13:10:56.433Z  

```py
# Printing a formatted string with workout details using an f-string
Math=90
Science=85
English=88

print(f"Math marks are: {Math}, Science marks are: {Science}, English marks are: {English}")




```
