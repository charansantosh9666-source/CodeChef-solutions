## Problem

### Validate Text Suffix

What will be the output of the following Python code?

```
text = "data_engineering"
result = text.endswith(("ring", "ing", "data"))
print(result)

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-27T04:31:38.049Z  

```cpp
# Define the filename of the image
filename = "photo.jpeg"

# Check if the file has a valid image extension (.jpg, .png, .gif)
is_image = filename.endswith((".jpg", ".png", ".gif"))

# Output the result (True if the file is an image, otherwise False)
print(is_image)
```
