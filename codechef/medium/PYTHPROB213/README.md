## Problem

### Calculate the area of a rectangle

In this example, we calculate the area of a rectangle using float multiplication. The formula for the area is:

```
area = length * width

```

Consider a rectangle with a length of 5.5 units and a width of 3.2 units. We can store these values in float variables:

- Length: 5.5
- Width: 3.2

When executed, the code will show the calculated area of the rectangle, illustrating how to work with float values in calculations in Python.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-06T02:22:29.288Z  

```py
length = 5.5  # Length of the rectangle
width = 3.2   # Width of the rectangle
area = length * width  # Calculating the area by multiplying length and width
print(area)  # This will output the area of the rectangle

```
