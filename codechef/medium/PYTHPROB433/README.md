## Problem

### Worked Example - Replace Words in a Greeting

In this example, we demonstrate how to use Python’s `replace()` method to update a greeting message. Specifically, we will replace the name "Alice" in the given text with "Bob" to personalize the message.

Consider the following variable:

```
message = "Happy Birthday, Alice! Wishing you a wonderful year ahead."

```

When the given code is executed, "Alice" will be replaced with "Bob," resulting in the following updated greeting:

```
Happy Birthday, Bob! Wishing you a wonderful year ahead.

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-24T01:42:18.987Z  

```py
# Declare a message with a greeting
message = "Happy Birthday, Alice! Wishing you a wonderful year ahead."

# Replace the name "Alice" with "Bob" in the message
new_message = message.replace("Alice", "Bob")

# Print the updated message
print(new_message)
```
