## Problem

### Worked Out Example - Calculate Fuel Efficiency

In this example, we calculate the average fuel efficiency of a vehicle, which is measured in kilometers per liter (km/L), using float division.

The average fuel efficiency can be calculated as follows:

```
fuel_efficiency = total_distance / total_fuel

```

To illustrate this, we can create the following variables:

- total_distance can be set to 450.75
- total_fuel can be set to 36.5

When executed, this code will yield the average fuel efficiency, demonstrating how float division is performed in Python.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-07T01:25:27.656Z  

```py
# Declare the total distance traveled as a float
total_distance = 450.75  

# Declare the total fuel consumed as a float
total_fuel = 36.5  

# Calculate the average fuel efficiency
fuel_efficiency = total_distance / total_fuel  

# Print the average fuel efficiency
print(fuel_efficiency)
```
