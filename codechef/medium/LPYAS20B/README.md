## Problem

Write a program to output the square of * (stars) of size 4 (check the output below).

```
  
  
  
   

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-27T05:11:05.502Z  

```py
# cook your dish here
for i in range(4):
    for j in range(4):
        print("*",end="")
    print()
```
