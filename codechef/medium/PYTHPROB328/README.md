## Problem

### Worked Example - Write a Short Story

In this example, we create a multi-line string to represent a short story. Multi-line strings are beneficial for writing longer texts while preserving line breaks, making them ideal for paragraphs or narrative text.

In Python, you can use triple quotes (`'''` or `"""`) to create a multi-line string. Any new line entered within the triple quotes will be preserved when printed.

This example illustrates how to effectively use multi-line strings in Python.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-11T01:11:34.154Z  

```py
# A multi-line string storing a story about Whiskers the cat
story = """Once upon a time, in a small village,
there lived a curious cat named Whiskers.
Every day, Whiskers would explore the fields
and chase butterflies under the warm sun.

One day, Whiskers discovered a hidden garden.
It was filled with colorful flowers and sweet fruits.
From that day on, the garden became Whiskers' favorite place,
where adventures awaited at every turn."""

# Printing the story to display it as defined
print(story)
```
