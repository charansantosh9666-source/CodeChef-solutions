## Problem

### Worked example - Printing Messages

In this example, we use the `print()` function to display multiple messages, separating them with empty lines for better organization and visual appeal.

The output will look like this:

```
Data Science is amazing!

Machine Learning is the future.

Artificial Intelligence is fascinating!

```

Using `print()` with no arguments creates blank lines between the messages, making the output easier to read. This approach helps enhance clarity when displaying several statements.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-31T13:07:02.152Z  

```py
# Step 1: Print the first message
print("Data Science is amazing!")

# Step 2: Print an empty line
print()

# Step 3: Print the second message
print("Machine Learning is the future.")

# Step 4: Print another empty line
print()

# Step 5: Print the third message
print("Artificial Intelligence is fascinating!")

```
