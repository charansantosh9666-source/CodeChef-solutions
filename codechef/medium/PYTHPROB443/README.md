## Problem

### Format a Sentence with join()

In this example, we demonstrate how to use Python’s `join()` method to insert a hyphen (“-”) between each character in the string “PYTHON,” creating a stylized version of the word.

Consider the following variable:

```
word = "PYTHON"

```

When the given code is executed, the output will be:

```
P-Y-T-H-O-N

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-27T04:23:57.702Z  

```py
word = "PYTHON"  # Given string

# Use join() to insert '-' between each character
formatted_word = "-".join(word)

# Print the formatted word
print(formatted_word)
```
