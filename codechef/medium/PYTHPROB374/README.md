## Problem

### Convert Greeting to Lowercase

You have a greeting, "GoodBye, See You Soon!" and you want to convert it to lowercase to maintain consistency. By using the lower() method, you’ll transform all letters to their lowercase form.

 **Expected Output** 
If your greeting was "Bye Penny!", then the program should print:

```
Bye Penny!
bye penny!

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-15T08:33:53.214Z  

```py
# Define the original greeting message
greeting = "GoodBye, See You Soon!"

# Convert the greeting to lowercase using the lower() method
print(greeting)

# Print the original and lowercase greeting messages
print(greeting.lower())
```
