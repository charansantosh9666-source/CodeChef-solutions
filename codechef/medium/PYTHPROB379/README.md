## Problem

### Format Animal Names in Title Case

You have a comma-separated string of animals in lowercase, "lion, elephant, zebra, giraffe".

You want to convert each animal’s name so that it starts with a capital letter, which can be done with the.title() method.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-15T08:39:04.091Z  

```py
# Given animal names in lowercase
animal_names = "lion, elephant, zebra, giraffe"

print(animal_names.title())
```
