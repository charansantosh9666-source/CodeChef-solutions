## Problem

### Clean Up Favorite Color Input

You have a dish name with leading or trailing spaces,

```
"     Pancake"

```

Your goal is to remove these extra spaces at the start and end, demonstrating the use of the strip() method.

Follow the comments given in the IDE and click on Submit to proceed.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-15T08:53:11.251Z  

```py
# Step 1: Declare the username with extra spaces
username = "     Pancake"

print(username)
print(username.strip())
```
