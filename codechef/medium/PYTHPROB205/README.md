## Problem

### Declare Float for Temperature

In this task, you are required to create a program that declares both an integer and a float for temperature readings.

 **Expected Output** 
After creating the variables and displaying the temperatures, your program should print the results as follows:

```
25
77.0

```

Feel free to change the temperature values to see how the output adjusts!
