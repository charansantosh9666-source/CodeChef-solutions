## Problem

### Calculate the Volume of a Cylinder

In this task, you are required to write a program to calculate the volume of a cylinder using float multiplication.

 **Data Values** 

- The radius is 2.5 units (float).
- The height is 7.0 units (float).
- We’ll use 3.14 as π (pi).

The formula for a cylinder’s volume is:
Volume = π × (radius)^2 × height

 **Expected Output** 
After performing the calculations, your program should print the resulting volume as follows:

```
137.375

```

Feel free to change the values of radius and height to see how the volume changes!

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-07T01:23:16.286Z  

```py
# Step 1: Declare the radius and height as float variables
radius = 2.5
height = 7.0
r2=radius * radius
p=3.14
print(p*r2*height)
```
