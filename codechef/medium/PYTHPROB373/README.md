## Problem

### Convert a Message to Lowercase

In this example, we demonstrate how to use the `lower()` method to convert a greeting message to lowercase. This method helps ensure consistent formatting by transforming all letters into their lowercase counterparts.

Consider the following string:

```
greeting = "WELCOME TO PYTHON PROGRAMMING!"

```

When the given code is executed, the output will be:

```
WELCOME TO PYTHON PROGRAMMING!
welcome to python programming!

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-15T08:31:18.694Z  

```py
# Define the original greeting message
greeting = "WELCOME TO PYTHON PROGRAMMING!"

# Convert the greeting to lowercase using the lower() method
lowercase_greeting = greeting.lower()

# Print the original and lowercase greeting messages
print(greeting)
print(lowercase_greeting)

```
