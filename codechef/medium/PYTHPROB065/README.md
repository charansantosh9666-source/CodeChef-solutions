## Problem

### Print Favorite Fruits with Separator

In this task, you are required to create a program that displays your favorite fruits using the `print()` function with the `sep` parameter to separate them.

You should display the following fruits:

- Apple
- Banana
- Cherry
- Date

 **Expected Output** 

```
apple->banana->cherry->date

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-31T13:02:20.252Z  

```py
# cook your dish here
print("apple","banana","Cherry","Date",sep="->");
```
