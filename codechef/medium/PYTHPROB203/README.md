## Problem

### Worked Example - Declare a Value of Pi

In this example, we declare a float variable to represent the value of pi (π). Pi is a fundamental mathematical constant that represents the ratio of a circle’s circumference to its diameter, with an approximate value of 3.14159.

Since pi is not an integer and has a decimal component, it’s important to store it as a float in Python. By including the decimal point in the assignment, Python recognizes the number as a floating-point value.

You can create a variable named `pi_value` and assign it the float value of `3.14159`:

```
pi_value = 3.14159

```

When executed, the code will display:

```
3.14159

```

This example illustrates how to work with floating-point numbers in Python.

```py
# Assign the value of pi (approximate to five decimal places) to the variable pi_value

print(pi_value)
```
