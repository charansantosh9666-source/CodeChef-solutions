## Problem

### Copy a Farewell Message

You have a farewell message: "Goodbye! Have a great day ahead!"

To demonstrate full string slicing, you’ll create an exact copy of this message without retyping it.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-13T08:15:29.629Z  

```py
# Assigning a string to the variable 'farewell'
farewell = "Goodbye! Have a great day ahead!"

# Create a copy of the 'farewell' string using slicing
farewell_copy = farewell[:]

# Print the copied string
print(farewell_copy)
```
