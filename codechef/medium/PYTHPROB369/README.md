## Problem

### Uppercase a Farewell Message

You have a farewell message, "goodbye, see you soon!" and you want to convert it entirely to uppercase.

This demonstrates how the upper() method in Python works on strings.

Output the message to the console once converted to upper case.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-15T08:27:42.229Z  

```py
# Define the original farewell message
farewell = "goodbye, see you soon!"

print(farewell.upper())

```
