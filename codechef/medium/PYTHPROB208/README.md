## Problem

### Calculate Final Water Level

In this example, we declare float variables to represent the water level of a reservoir before and after certain changes. By performing addition and subtraction, we can see how to update the water level based on rainfall and water usage.

To illustrate this, we can create the following variables:

- initial_level assigned the float value 1234.56
- rainfall assigned the float value 78.34
- water_usage assigned the float value 45.67

Next, we calculate the updated water level by adding rainfall and subtracting water usage from the initial level:

```
updated_level = initial_level + rainfall - water_usage

```

When executed, the code will display the updated water level, demonstrating how to manipulate float values in Python.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-04T14:18:48.866Z  

```py
# Declare the initial water level of the reservoir as a float
initial_level = 1234.56  

# Declare the amount of rainfall as a float
rainfall = 78.34  

# Declare the water usage as a float
water_usage = 45.67  

# Calculate the updated water level by adding rainfall and subtracting water usage
updated_level = initial_level + rainfall - water_usage  

# Print the updated water level
print(updated_level)
```
