## Problem

### Debug

In this task, you are required to fix errors in the provided code that uses the `print()` function incorrectly. The errors are due to the improper placement of the `sep` parameter, causing the output to differ from what’s expected.

Your program should ultimately output the following format:

```
Python, is, awesome
Let's, learn, to, code.

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-31T13:01:02.640Z  

```py
# debug the code written below 
print("Python", "is", "awesome", sep=", ")
print("Let's", "learn", "to", "code.", sep=", ")
```
