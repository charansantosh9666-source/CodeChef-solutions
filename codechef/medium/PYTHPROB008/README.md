## Problem

### Worked example - Total Cost of Groceries

In this example, we demonstrate how to add the prices of three items—apples, bananas, and oranges—using the `+` operator in Python.

Consider the following prices:

- Apples: $3
- Bananas: $2
- Oranges: $4

By summing these prices, you can determine the total cost.

When executed, the code will show:

```
9

```

This output illustrates how simple addition can be used to calculate the total cost of items effectively.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-01T11:35:40.421Z  

```py
# Declaring the prices of the items
apples = 3
bananas = 2
oranges = 4

# Performing addition to calculate total cost
total_cost = apples + bananas + oranges

# Displaying the total cost
print(total_cost)  # This will output: 9

```
