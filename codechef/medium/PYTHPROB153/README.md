## Problem

### Checks which Team wins a cricket

In this example, we will determine whether Team B wins a cricket match by comparing their score against the target set by Team A.

 **Match Details:** 

- Team A’s Target Score: 200
- Team B’s Actual Score: 210

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-10T03:23:03.505Z  

```py
# Step 1: Create two variables for Team A's target and Team B's score
team_a_target = 200
team_b_score = 210

# Step 2: Compare scores to determine if Team B wins
if team_b_score > team_a_target:            # Is Team B's score greater than Team A's target?
    print("Team B wins!")                   # Print the result if Team B wins


```
